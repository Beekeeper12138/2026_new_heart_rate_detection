# 心率识别系统技术文档

## 项目概述

本项目实现了一种基于远程光电容积描记术(rPPG)的非接触式心率检测系统，通过摄像头视频流检测面部皮肤颜色变化来实时估计心率，无需传感器与人体接触。

### 核心技术特点

- **深度学习皮肤语义分割**：使用UNet11模型进行皮肤像素分割，提高ROI选择的准确性
- **高级信号处理**：集成POS算法、小波变换、卡尔曼滤波等先进技术
- **环境光补偿**：自动检测和补偿环境光变化，提高在不同光照条件下的准确性
- **多ROI融合**：从多个面部区域提取信号并融合，降低噪声干扰
- **自适应参数调整**：根据信号质量、运动水平和光照条件自动调整系统参数
- **多人同时监测**：支持多个人脸的同时心率监测
- **低分辨率摄像头适配**：优化算法以适应低分辨率摄像头
- **实时性能优化**：使用模型压缩、多线程并行处理等技术提高实时性能

## 系统架构

### 整体架构

```
┌───────────────┐     ┌───────────────┐     ┌───────────────┐
│ 前端应用      │────>│ 后端服务器    │────>│ 心率检测服务  │
│ (Web界面)     │<────│ (FastAPI)     │<────│ (rPPG算法)    │
└───────────────┘     └───────────────┘     └───────────────┘
```

### 核心模块

1. **视频捕获模块**：从摄像头或视频文件获取视频帧
2. **面部检测模块**：使用OpenCV的Haar级联分类器检测人脸
3. **皮肤分割模块**：使用UNet11深度学习模型分割皮肤像素
4. **信号处理模块**：提取、滤波和分析rPPG信号
5. **心率估计模块**：通过FFT计算功率谱密度，估计心率
6. **WebSocket通信模块**：实现前端与后端的实时数据传输

## 技术实现细节

### 1. 皮肤语义分割

- **模型**：UNet11预训练模型
- **优化**：使用JIT编译和量化技术提高推理速度
- **预处理**：应用对比度增强和光照归一化，提高在不同光照条件下的性能
- **自适应阈值**：根据预测结果自动调整分割阈值

### 2. 信号处理

- **POS算法**：用于提取rPPG信号，提高信号质量
- **小波变换**：用于信号去噪，保留信号特征的同时去除噪声
- **卡尔曼滤波**：用于信号平滑，提高心率估计的稳定性
- **多ROI融合**：从额头、左右脸颊、鼻子等多个区域提取信号并加权融合

### 3. 环境光补偿

- **光照检测**：实时监测环境光强度
- **自适应补偿**：根据光照强度自动调整信号处理参数
- **光照历史**：使用滑动窗口记录光照变化历史，实现平滑补偿

### 4. 自适应参数调整

- **信号质量监测**：实时评估信号质量，调整相应参数
- **运动水平估计**：通过连续帧的差异估计运动水平，调整滤波和平滑参数
- **光照条件适应**：根据光照强度调整信号处理策略

### 5. 多人同时监测

- **多线程处理**：使用ThreadPoolExecutor实现并行处理
- **人脸跟踪**：为每个人脸分配独立的信号缓冲区和处理参数
- **结果关联**：确保心率结果与对应的人脸正确关联

### 6. 低分辨率摄像头适配

- **图像增强**：应用锐化、对比度增强等技术提高图像质量
- **参数优化**：为低分辨率信号调整滤波参数、缓冲区大小等
- **鲁棒性增强**：降低信号质量阈值，提高在低质量信号下的检测能力

## 部署指南

### 环境要求

- **操作系统**：Windows 10/11, Linux, macOS
- **Python版本**：3.8+
- **依赖库**：
  - OpenCV
  - NumPy
  - SciPy
  - PyTorch
  - PyWavelets
  - FastAPI
  - Uvicorn
  - WebSockets

### 安装步骤

1. **克隆项目**
   ```bash
   git clone https://github.com/nasir6/rPPG.git
   cd rPPG
   ```

2. **安装依赖**
   ```bash
   # 安装后端依赖
   cd backend
   pip install -r requirements.txt
   
   # 安装rPPG模块依赖
   cd rPPG
   pip install -r requirements.txt
   ```

3. **下载模型文件**
   - 确保 `linknet.pth` 模型文件存在于 `backend/rPPG/` 目录

4. **启动服务器**
   ```bash
   cd backend
   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
   ```

5. **访问前端**
   - 打开浏览器，访问 `http://localhost:8000`

### 配置选项

- **服务器配置**：修改 `backend/config.py` 文件中的配置参数
- **算法参数**：在 `RPPGService` 类的初始化方法中调整算法参数
- **前端配置**：修改 `frontend/js/config.js` 文件中的配置参数

## 使用说明

### 基本使用

1. **启动系统**：按照部署步骤启动后端服务器

## 故障排除

### 常见问题

1. **摄像头无法访问**
   - 检查浏览器是否授予了摄像头权限
   - 确保摄像头没有被其他应用占用

2. **无法检测到人脸**
   - 确保光线充足
   - 调整摄像头角度，确保面部清晰可见
   - 检查面部是否在摄像头视野范围内

3. **心率检测不准确**
   - 确保面部与摄像头保持适当距离（约30-60cm）
   - 减少头部运动
   - 确保环境光稳定

4. **系统运行缓慢**
   - 关闭其他占用系统资源的应用
   - 降低摄像头分辨率
   - 确保使用的是性能较好的设备
