# 无损视频覆盖矩形框解决方案

## 问题分析

当前实现通过以下方式处理视频流：
1. 前端捕获视频帧并转换为base64
2. 后端接收、处理、绘制矩形框并重新编码
3. 前端接收并显示处理后的视频帧

这种方式会导致视频质量下降，因为：
- 前端捕获时的JPEG压缩
- 后端处理后的重新编码
- 双重压缩导致的质量损失

## 解决方案

采用**前端覆盖层**方案，在不修改原始视频的情况下添加矩形框：

### 1. 后端修改
- 修改WebSocket响应，只发送人脸坐标数据，不发送处理后的视频帧
- 保持原始视频流完整无损

### 2. 前端实现
- 使用CSS层叠技术，在原始视频上方创建透明覆盖层
- 通过Canvas或HTML元素绘制矩形框
- 使用绝对定位确保矩形框与视频内容精确对齐

### 3. 技术实现

#### 后端修改
- 修改 `websocket_routes.py`，移除图像编码和传输
- 修改响应格式，只包含人脸坐标和心率数据

#### 前端修改
- 恢复原始视频显示，移除当前的canvas替换逻辑
- 创建独立的覆盖层元素，用于绘制矩形框
- 实现坐标转换，确保矩形框与视频内容对齐
- 使用requestAnimationFrame优化渲染性能

### 4. 技术优势

- **无损视频质量**：原始视频流完全不变
- **低延迟**：减少数据传输量，提高实时性
- **精确覆盖**：通过坐标转换确保矩形框精确定位
- **无压缩损失**：避免双重JPEG压缩
- **高性能**：前端渲染效率高，适合实时视频流

### 5. 实现步骤

1. 修改后端WebSocket响应格式
2. 前端恢复原始视频显示
3. 创建覆盖层绘制系统
4. 实现坐标转换逻辑
5. 优化渲染性能
6. 测试不同分辨率和场景的兼容性
